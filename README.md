
# QuickNotes App

A simple notes application for creating, organizing, searching, and deleting notes.

## Features

- Create notes with text and categories.
- Display the date and time each note was created.
- Delete individual notes.
- Save notes in localStorage so they persist after refreshing.
- Search notes by text without case sensitivity.
- Display a message when no notes match a search.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Browser localStorage

## How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a browser, or use VS Code Live Server.

## Project Files

- `index.html` — page structure and form.
- `style.css` — app styling.
- `script.js` — note creation, rendering, deletion, persistence, and search.
- `README.md` — project documentation.
